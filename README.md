## 🚧 Featured project

### 🎬 [ticket-booking-backend](https://github.com/f0restron07/ticket-booking-backend)
A BookMyShow-style movie ticket booking backend, built the way a production one would be: schema-first, containerised, and designed so two people clicking the same seat at the same moment can never both get it.
